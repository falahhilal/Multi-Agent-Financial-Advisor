# Shared Agent Contracts

Status: Draft v1 — pending team review.

## Architecture

1. User questionnaire goes to Risk Profiler.
2. Macro Agent independently analyses macroeconomic data.
3. Sector Agent independently analyses PSX company data and sentiment.
4. Debate Agent receives Macro and Sector outputs only.
5. Portfolio Constructor receives Risk Profiler constraints and Debate output.
6. Portfolio allocation calculations are performed using deterministic Python.

## Agent responsibilities

| Agent | Input | Output |
|---|---|---|
| Risk Profiler | Investor questionnaire | Risk constraints |
| Macro | Macroeconomic indicators | Macro analysis |
| Sector | Company data and sentiment | Sector and stock analysis |
| Debate | Macro and Sector outputs | Debate conclusions |
| Portfolio Constructor | Risk constraints and Debate output | Final allocations |

## Important boundaries

- Macro and Sector must not receive investor questionnaire answers.
- Debate must not receive Risk Profiler output.
- Portfolio Constructor must not receive the raw questionnaire.
- Portfolio weights and metrics must be calculated in Python, not generated by an LLM.
- All source citations must refer to actual source records.
- All models reject undeclared fields.

## Validation rules

- Confidence scores range from 0 to 1.
- Percentages range from 0 to 100.
- Portfolio weights must sum to exactly 100%.
- A portfolio must contain exactly one CASH allocation.
- Equity allocation must respect the maximum equity constraint.
- Cash allocation must respect the minimum cash constraint.
- Each individual stock must respect the maximum single-stock constraint.
